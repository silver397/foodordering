# Food Ordering API

This contain the link to the presentation slide https://canva.link/yik7e55sx88dp6m

A backend REST API for a food ordering platform. It allows users to register, log in, browse restaurants and menu items, and manage food orders.

## Features

- User registration and login
- JWT authentication
- Password hashing with bcrypt
- Restaurant management
- Menu item management
- Category management
- Order management
- Role-based access control
- Error handling

## Technologies

- Node.js
- Express.js
- PostgreSQL
- JWT
- bcrypt
- dotenv
